## 🏗 Архитектура проекта

Пайплайн состоит из четырех ключевых этапов:

1. **Сбор данных (Web Scraping & API Data Collection):**
   - Модульный парсер (`scraper.py`) для агрегации новостей из разнородных источников:
     - **ТАСС:** REST API с поддержкой курсорной пагинации (`search_after`).
     - **Lenta.ru:** Исторический архив новостей с парсингом структуры страниц через BeautifulSoup4.
     - **Телеканал «Дождь»:** Обработка динамической подгрузки новостных лент.
   - Очистка от служебных артефактов, временных меток регулярными выражениями (RegEx) и дедупликация на лету.

2. **Предобработка и токенизация (`data_mock.py`, `vectorizer.py`):**
   - Приведение к нижнему регистру, фильтрация пунктуации и спецсимволов.
   - Токенизация текста и удаление русскоязычных стоп-слов, а также односимвольных токенов.
   - Построение словаря уникальных токенов и представление текстов в виде мешка слов (**Bag of Words, BoW**).

3. **Классификация (Machine Learning from Scratch):**
   - Самостоятельная реализация трёх алгоритмов многоклассовой классификации на чистом NumPy (One-vs-Rest):
     - **Наивный байесовский классификатор (Multinomial Naive Bayes)** со сглаживанием Лапласа.
     - **Логистическая регрессия (Multiclass Logistic Regression)** с градиентным спуском.
     - **Метод опорных векторов (Linear Support Vector Machine / SVM)** с субградиентным спуском (Pegasos).

4. **Оценка качества и аналитика (`metrics.py`):**
   - Расчёт Accuracy, Macro-F1, Precision, Recall для каждого класса, построение матрицы ошибок (Confusion Matrix) и Classification Report.

## 🧠 Модели машинного обучения

Все модели реализованы без использования Scikit-learn:

* **Multinomial Naive Bayes (`naive_bayes.py`):**
  Оценивает априорные вероятности классов P(C) и условные вероятности слов P(w_i | C) со сглаживанием Лапласа (alpha = 1.0). Вычисления проводятся в логарифмической шкале для предотвращения underflow.
* **Logistic Regression (`logistic_regression.py`):**
  Схема One-vs-Rest (OvR). Оптимизация бинарной кросс-энтропии с помощью пакетного градиентного спуска с настраиваемым темпом обучения alpha и количеством эпох.
* **Linear SVM (`svm.py`):**
  Схема One-vs-Rest (OvR). Минимизация функции потерь Hinge Loss с L2-регуляризацией через субградиентный спуск.

## 🚀 Быстрый старт

### Установка

Клонируйте репозиторий и настройте виртуальное окружение:

```bash
git clone https://github.com/shneine/news-classificator.git
cd news-classificator

python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

### Запуск тестов

Проект полностью покрыт модульными тестами (21 тест на предобработку, векторизацию, математику моделей и инварианты пайплайна):

```bash
python tests.py
```

### Интерактивный режим (CLI меню)

Запустите `main.py` без параметров для входа в удобное консольное меню:

```bash
python main.py
```

В меню доступны:
1. Обучение всех трех моделей на выбранном датасете с выводом Classification Report и Confusion Matrix.
2. Интерактивная классификация произвольного введённого заголовка в реальном времени.
3. Пакетное сравнение моделей на всех доступных датасетах из папки `data/`.
4. Просмотр баланса классов в датасетах.

### Обучение и инференс через CLI

Обучить модели на конкретном файле и сразу классифицировать заголовок:

```bash
python main.py --csv data/dataset.csv --test-size 0.3 --predict "Центробанк повысил ключевую ставку из-за инфляции"
```

Результат:
```text
Предсказания для заголовка: «Центробанк повысил ключевую ставку из-за инфляции»
  Naive Bayes: Экономика
  Logistic Regression: Экономика
  Linear SVM: Экономика
```

### Сбор новых данных (Скрапер)

Для запуска пайплайна парсинга свежих новостей из ТАСС, Lenta.ru и Дождя:

```bash
python scraper.py
```
Собранные данные будут автоматически сохранены в `data/test_dataset.csv`.
